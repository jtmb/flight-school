# Presentation reference — model guidance only

The user's reference is the [OpenCode README](https://github.com/anomalyco/opencode/blob/dev/README.md): clear identity, a brief description, a strong product visual, and practical installation information. Apply that hierarchy to a game without copying its brand or reproducing all of its sections.

Inspect [the fictional still](model-only/mock-gameplay-reference.png) when a visual reference helps. The [fictional animation](model-only/mock-gameplay-reference.gif) illustrates a short gameplay-like loop. These are generated mock artwork, not recorded gameplay and not evidence that any game works. They are included solely for the model to inspect.

## What to transfer

- Give one actual gameplay view most of the visual attention.
- Frame the action tightly enough to understand it at README width.
- Use the game's own colors and art direction.
- Put a short setup section immediately after the visual.
- Let spacing and hierarchy do the work; keep copy specific and brief.

## What must stay inside this skill

The mock art, CINDERWING name, imagined features, and illustrative controls are reference-only. Do not put these files, their paths, or a reproduction of their contents in a real game's README or public media directory. Do not claim the reference was captured from the user's game. The public README should show the user's actual game.

The reference animation is only about two seconds long. Do not copy that duration mechanically; capture enough real play to make the actual game understandable. The companion skill gives practical capture and encoding defaults.

## Intended composition

Read the following as an ordering guide, not content to publish:

1. Actual game title and a single sentence describing play.
2. Real gameplay GIF with accurate alt text.
3. Necessary prerequisites and a short verified command block.
4. A small controls table, if useful.
5. Optional build details and existing project links.

The editable scaffold lives at `../assets/README.template.md`. Its placeholders are instructions to replace, not acceptable final content.
